# Windows 11 - FIrewall & Microsoft Store Failure

**Full project documentation and dedicated repository:**
[Windows11-Firewall-Recovery](https://github.com/Jevlab/Windows11-Firewall-Recovery)

## Quick Summary
Diagnosed and resolved a Windows 11 system failure caused by a corrupted update
that broke the Windows Defender Firewall and escalated into complete Microsoft Store
failure. Tested all standard repair tools before reaching out to Microsoft Support
and performing a full clean OS reinstall via bootable USB.

## Tools Used
PowerShell, SFC, DISM, services.msc, winver, Windows ISO, Media Creation Tool, Bootable USB, Google Drive

## Outcome
Resolved. Full system stability restored after clean OS reinstall.
