## Quick Summary
Diagnosed and resolved a Windows 11 system failure caused by a corrupted update 
that broke the Windows Defender Firewall and cascaded into complete Microsoft Store 
failure. Exhausted all standard repair tools before escalating to Microsoft Support 
and performing a full clean OS reinstall via bootable USB.

## Tools Used
PowerShell, SFC, DISM, services.msc, winver, Windows ISO, Bootable USB, Google Drive

## Outcome
Resolved. Full system stability restored after clean OS reinstall.
